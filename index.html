📍 Location ki ijazat band hai. Ye karein:
1) Browser ke menu (⋮) dabayein → Settings → Site settings → Location — wahan SOSKaro ko Allow karein.
2) Phone ki apni Location bhi ON rakhein.
3) Phir neeche wala button dobara dabayein.
Permission is off — allow Location for this site in browser settings, then retry.

📍 Phone ki Location ON karein. Ye karein:
1) Upar wale panel ko neeche kheench kar Location / GPS wala button ON karein (ya phone ki Settings se).
2) Khuli jagah, aasman ke neeche jayein — ghani imaraton mein GPS kamzor hota hai.
3) Phir neeche wala button dobara dabayein.
Turn the phone's Location ON, go near open sky, then retry.

Rahnumai — hifazat ki hidayat
Sab se mehfooz kamra: ghar ka sab se andar wala kamra, khirkiyon aur sheeshay se door. Neeche wali manzil behtar hai.
Safest room: the innermost room, away from windows.
Tayyar rakhein: peene ka paani, torch, power bank, zaroori dawa, kuch khana, phone charge.
Keep ready: water, torch, power bank, medicines, food.
Roshni ka SOS ishara: 3 chhoti chamak, 3 lambi chamak, 3 chhoti chamak — matlab: "madad chahiye". Ye app yehi ishara deti hai.
SOS light signal: 3 short, 3 long, 3 short flashes.
Milne ki jagah ghar walo se pehle tay karein, aur Setup mein save karein.
Decide a family meeting point in advance and save it in Setup.
Battery bachayein: jab istemal na ho to phone airplane mode par rakhein; SOS sirf zaroorat par chalaye.
Save battery: use airplane mode when idle.
Is app ki hadein: awaz/roshni ka signal sheher mein ~50 meter tak; call aur SMS ke liye mobile tower zaroori; GPS ke liye khula aasman chahiye. Ye app kisi sarkari service se nahi juri hui — asli khatre mein pehle khud ko mehfooz jagah le jayein.
Honest limits: signal ≈50 m in a city; calls/SMS need towers; GPS needs open sky.
